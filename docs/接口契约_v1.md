# 第五组跨组接口契约 v1

- 契约版本：`1.0`
- 状态：第五组实现基线；第2–4组真实适配待联调
- 事实定义：`contracts/schemas.py`、`contracts/validation.py`

## 1. 集成入口

第五组提供两个入口：

1. 自然语言入口：调用已注册的第一组，再进入核心编排。
2. 结构化入口：直接接收已经通过v1契约校验的任务信封。

第一组公共接口保持：

```text
HostAgent().understand_intent(user_input, history=None)
```

第一组成功结果为 `intent + target + action + params`。第一组错误码
`1001–1004` 分别映射为 `E0101–E0104`，原错误保留在 `cause` 中。

## 2. 标准任务信封

```json
{
  "contract_version": "1.0",
  "task_trace_id": "task UUID",
  "attempt_id": "attempt UUID",
  "timestamp": "ISO-8601",
  "intent": {
    "category": "应用控制|文件操作|系统设置|信息查询",
    "action": "open",
    "target": "Files",
    "params": {},
    "raw_text": "打开文件管理器"
  }
}
```

`task_trace_id` 标识完整用户任务；补参或恢复仍使用同一任务ID，但生成新的
`attempt_id`。

## 3. 编排阶段与状态

阶段包括：

```text
intent → security → planning → detection → execution
→ tool_authorization → tool_execution → persistence → completed
```

结果状态包括：

```text
completed / failed / needs_input / needs_confirmation
needs_redetection / tool_required / cancelled
cancelled_with_side_effects / partial_failure
```

`success=true` 只允许与 `status=completed` 同时出现。

## 4. 第二组接口

第五组内部将第二组拆成两个逻辑阶段：

- `plan(request)`：生成步骤数组。
- `detect(request)`或`detect_elements()`：返回控件对象或数组。

如果第二组一次返回 `steps + elements`，适配器会拆分为两个阶段。如果旧模块
没有检测能力，结果明确标记为 `degraded`，不能表示为真实检测完成。

## 5. 第三组接口

第三组执行状态：

- `completed`：整计划完成。
- `needs_redetection`：返回 `failed_step_id`、`completed_step_ids` 和非空检查点。
- `tool_required`：返回工具请求和非空检查点。
- `failed`：不可恢复失败。

控件失效时第五组只重新检测一次，并携带检查点恢复；第二次仍失效返回
`E3003`。

## 6. 第四组工具请求

工具请求必须包含：

```json
{
  "tool_call_id": "唯一ID",
  "tool_name": "注册工具名",
  "arguments": {}
}
```

第五组负责去重、安全授权和调用第四组。工具失败、超时、未知工具或重复ID
都会使整体任务失败，不能降级为普通成功。

## 7. 风险处置

| 风险 | 行为 |
|---|---|
| low | 自动放行 |
| medium | 在授权范围内自动放行 |
| high | 规划前返回 `needs_confirmation` |
| critical | 无条件拒绝 |

确认请求一次消费、会过期，并绑定原始任务快照。确认响应不能替换原动作或参数。

## 8. 超时与重试

默认阶段超时：意图20秒、安全1秒、规划15秒、检测5秒、执行60秒、工具15秒。
规划和安全允许有限重试；执行器和工具不进行盲目异常重试。

## 9. 兼容性

- 旧 `IntentJSON` 与旧 `orchestrate()` 暂时保留。
- 未声明版本的现有Mock以 `legacy` 模式注册。
- 显式声明未知契约版本的模块在启动阶段拒绝。
- 最终真实联调只能调整适配器，不能绕过v1核心契约。
