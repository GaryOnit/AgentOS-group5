## 5. 质量观察与说明

### 5.1 关于 numpy 依赖

当前实现支持：
- 有 numpy：使用 numpy 计算 TF-IDF
- 无 numpy：自动降级到纯 Python 计算（功能一致，性能下降）

因此在教学环境下可保证“可运行优先”。

> 【截图占位-T07】无 numpy 降级提示日志截图
